# assets/ — обязательные файлы

Раньше эта папка была пустой, и это была подтверждённая причина бага из ТЗ
п.2.4 («Ваша карта готова», а дальше ничего не приходит): `card_image.py`
не мог отрендерить карту без этих файлов и падал с исключением уже после
отправки текста «карта готова».

Сейчас файлы на месте:

- `reyma_logo.png` — логотип Reyma (PNG с прозрачным фоном)
- `NothingYouCouldDo-Regular.ttf` — рукописный шрифт для номера карты
  (взят из оригинальной папки проекта, лицензия — `OFL.txt` рядом)

**Важно:** при следующей выгрузке в GitHub убедиться, что эта папка
реально попадает в коммит целиком — раньше именно из-за неполной
drag-and-drop загрузки этих файлов не было на проде.

Код также подстрахован на случай, если файлы снова пропадут:
- при старте бота — `bot.py` пишет `logger.error(...)` в лог Railway,
  если файла нет;
- при показе карты — `send_card_and_pin` в `bot.py` перехватывает
  исключение, логирует его и присылает пользователю понятное сообщение
  вместо тишины.
